# What is in this repository

This is a curated public reference, not a mirror of Z-SPAN's complete working
repository.

Being transparent does not require placing every operational file on a public
shelf. It requires making the boundary understandable: what a reader can
inspect here, what they cannot inspect here, and which conclusions the
published material can support.

## Included in this public library

The current public collection contains:

- Home, place, channel, city, search, and public-ledger views.
- Guide cards, map presentation, inline playback, and expanded playback.
- A shared video-player boundary for multiple source types.
- Timed-word presentation used alongside source video.
- Visitor-facing audit, ribbon-scan, and verification views.
- The styles used by those selected surfaces.
- Three canonical, self-contained prompt artifacts preserved unchanged.
- The runnable Respawn Kernel: country-neutral contracts, locale packs,
  repository generator, validator, Arizona normalized-record adapter, static
  reference library, tests, and public bootstrap documentation.
- Public documentation explaining how to read the material.
- PolyForm Noncommercial 1.0.0 terms and the required project notice.

The exported source is grouped under `code/visitor-interface/` for public
reading. Its internal `src/` relationships are preserved, and the catalog
records how to approach each shelf.

## Not included

This repository intentionally omits:

- The complete application shell and dependency graph required to run the
  interface.
- Server-side services, APIs, databases, and production infrastructure.
- Collection, processing, and internal data-management systems.
- Executable per-source collection recipes, credentials, and country-specific
  private registries. Respawn defines their boundary but does not publish them.
- Private operational tools and review surfaces.
- Deployment configuration, local runtime settings, and credentials.
- Internal records, working conversations, and unpublished project material.
- The rest of the private prompt collection, including prompts coupled to
  unpublished processing systems or private development history.
- Features that have not been approved for public presentation.

An import that points to a file outside the published tree therefore does not
mean the export accidentally lost a file. It means the readable source crosses
an intentional publication boundary.

## What can be inspected here

The repository supports close reading of the approved visitor-interface code
and direct use of the separately bounded Respawn Kernel:

- How places and meetings are presented.
- How the guide and search surfaces organize public material.
- How several video sources are adapted behind one player interface.
- How source links and integrity-related views appear to a visitor.
- How the visual language is expressed in the selected styles.
- How an independent country project can model recursive jurisdictions,
  normalize verified meeting records, validate a seed, and render a
  multilingual static library without the private Arizona runtime.

## What cannot be concluded from it

The repository cannot, by itself, establish how Z-SPAN's private services
collect or process material, how production infrastructure is configured, or
whether every behavior on the live site is represented in this snapshot.

For the current public experience, visit [zspan.org](https://zspan.org). For
the exact state of this release, see
[`docs/snapshots/2026-08-02.md`](docs/snapshots/2026-08-02.md).

## How the boundary is maintained

Public snapshots and the Respawn release are built from explicit approved
paths rather than
by copying the private repository and trying to remove sensitive material
afterward. Each candidate is staged separately, reviewed as a complete tree,
and checked for credentials, local paths, private wording, development
comments, and files outside the approved surface before it reaches the public
repository.

Future snapshots may widen or narrow this boundary. Any change should be
described in its dated snapshot record rather than silently changing what this
repository claims to represent.
