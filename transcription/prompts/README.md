# Prompt shelf

This shelf preserves three small prompt artifacts that can be examined or
adapted independently:

- [`newsletter.md`](newsletter.md) turns a meeting record into a short civic
  digest.
- [`whats_next.md`](whats_next.md) extracts upcoming actions, dates, and
  follow-ups.
- [`council_sentiment.md`](council_sentiment.md) produces a brief neutral
  observation and a restrained visual indicator of meeting tension.

The three files are copied unchanged from canonical working-project versions.
Their NotebookLM labels describe the historical environment in which they
were developed; they are not documentation of Z-SPAN's current private
runtime.

The wider private prompt collection is not published. Many of those files are
tied to unpublished processing systems, private development history, or
features that are not ready for a public shelf. Inclusion here is therefore an
individual editorial decision, not an automatic export of a private folder.

These prompts are reference material rather than guaranteed outputs. Anyone
adapting them should test the result against their own records, privacy rules,
source requirements, and local context.
