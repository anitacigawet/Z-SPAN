**Isang virtual na aklatan para sa lokal na politika.**

[Bisitahin ang Z-SPAN sa zspan.org](https://zspan.org)

✨ **Inilathala nang buo, para sa sinuman. Pinalalawak sa tulong ng sinuman.**

Ang Z-SPAN ay isang pagtatangkang gawing mas madaling hanapin, panoorin, at
unawain ang mga lokal na pampublikong pulong. Ang mga lugar ay nagiging mga
channel, ang mga pulong ay nagiging mga episode, at nananatiling bahagi ng
landas ang mga orihinal na video, agenda, at katitikan.

Nilalaman ng repository na ito ang mismong gumaganang aklatan: ang website,
pampublikong API, mga parser ng pinagmumulan ng pulong, daloy ng pagproseso,
lokal na client, at mga pagsusuring nagpapanatiling nakaugnay sa pampublikong
rekord ang nabuong gawain. Simple ang dahilan sa paglalathala ng buong
mekanismo: ang aklatang pinananatili ng isang tao ay nagtatapos kasama ng taong
iyon. Hindi gayon ang aklatang maaaring suriin, patakbuhin, kuwestiyunin, at
ipagpatuloy ng ibang tao.

Nasa hiwalay na
[National Civics Catalog](https://github.com/anitacigawet/national-civics-catalog)
ang direktoryo ng mga pinagmumulan ng pulong ng pamahalaan. Patuloy na
gumaganang mga pampublikong endpoint at ebidensiya ang nilalaman ng repository
na iyon—hindi mga parser, transcript, buod, o naprosesong pulong ng Z-SPAN.
Isang halimbawa ang Z-SPAN ng maaaring buuin mula rito.

## 🗺️ Isang pambansang direktoryo, binubuo lugar kada lugar

Ang Arizona ang pampublikong patunay ng konsepto na kasalukuyang pinoproseso at
inilalathala ng Z-SPAN. Binibigyan din ng direktoryo ng channel ang bawat estado
at teritoryo ng tunay na panimulang balangkas, na nakaayos sa mga pampublikong
katawan sa antas ng estado, katumbas ng county, Tribal, panrehiyon, at lokal.

May mga nailathalang pulong ng Z-SPAN ang mga berdeng estante. Tapat na gawaing
kasalukuyang isinasagawa ang mga amber na estante: nasa direktoryo ang lugar,
ngunit kailangan pa ng pansin ang patuloy nitong pinagmumulan ng pulong o parser
ng Z-SPAN. Walang kailangang maghintay ng paanyaya upang tulungan ang sarili
nilang komunidad.

## 🐈 Tulungan ang iyong bayan

1. Hanapin ang iyong estado at lugar sa [zspan.org](https://zspan.org).
2. Kung naghihintay ang estante, i-click ang natutulog na pusa.
3. Kopyahin ang maikling handoff sa Markdown sa AI assistant na ginagamit mo
   na.
4. Sagutin ang ilang karaniwang tanong tungkol sa lugar at opisyal nitong pahina
   ng mga pulong. Hindi mo kailangang marunong ng JSON o Git.
5. Kung available ang mga tool ng GitHub, maaaring maghanda ang assistant ng
   isang nakatuong pull request para sa iyong kumpirmasyon. Kung hindi, maghahanda
   ito ng kumpletong ulat para sa isang simpleng GitHub form.

Mapupunta ang kontribusyon sa National Civics Catalog, kung saan sinusuri ng
isang pinagkakatiwalaang checker at isang tao ang endpoint at ebidensiya nito.
Hindi ito kailanman direktang inilalathala sa Z-SPAN.

**Ang tatlong-araw na pangako ng Z-SPAN:** kapag tinanggap ang isang kontribusyon
sa catalog, gagawin ng Z-SPAN ang kaukulang parser o maglalathala sa loob ng
tatlong araw ng nakikitang resultang nagpapaliwanag na nahahadlangan ng source
ang pagpapatuloy. Ang pangakong ito ay tungkol sa paggawang magagamit ang source
o sa tapat na pagpapaliwanag kung bakit hindi pa ito magagamit—hindi sa
awtomatikong paglalathala ng nilalaman ng pulong na ginawa ng AI.

[Basahin ang mga tagubilin sa pagkokontribusyon gamit ang AI](https://github.com/anitacigawet/national-civics-catalog/blob/main/contribute/AI-INSTRUCTIONS.md)

## 📚 Bakit umiiral ang aklatang ito

Madalas na pare-pareho ang mga tanong na kinakaharap ng mga proyektong
gumagamit ng lokal na pampublikong rekord:

- Paano dapat mag-browse ng mga pulong kung magkakaiba ang pagkakaayos ng bawat
  website ng pamahalaan?
- Paano mananatiling kapaki-pakinabang ang iisang interface sa iba't ibang
  lugar at video provider?
- Paano mananatiling malinaw ang daan pabalik sa opisyal na pinagmulan?
- Paano maipaliliwanag ng mga teknikal na sistema ang kanilang sarili nang hindi
  ipinababasa sa mga tao ang database sa ilalim nito?

Ang Z-SPAN ay isang gumaganang sagot, hindi ang tanging sagot. Layunin ng
repository na panatilihing nakikita ang kabuuan nito—upang masuri, makuwestiyon,
at madala pa nang mas malayo ng mga taong gumagamit nito.

## 👋 Para kanino ang aklatang ito

Mag-aaral, aktibista, mamamahayag, mananaliksik, designer, developer,
boluntaryo, o sadyang interesado ka man sa lokal na pampublikong impormasyon,
hindi mo kailangang gamitin ang buong proyekto upang may mapakinabangan dito.
Nakaayos ang aklatan upang maunawaan ang isang ideya o bahagi sa bawat
pagkakataon—at upang makapagdagdag ng isang lugar sa bawat pagkakataon.

## 🗂️ Paano nakaayos ang repository na ito

- [`council_navigator`](../02_Core_Project/council_navigator/) — ang website,
  pampublikong API, lokal na cache ng mga pulong, at pampublikong direktoryo ng
  channel.
- [`parsers`](../02_Core_Project/council_navigator/parsers/) — mga parser ng
  kalendaryo para sa bawat source na ginagawang iisang karaniwang anyo ng pulong
  ang mga endpoint sa catalog.
- [`zspan_pipeline`](../02_Core_Project/zspan_pipeline/) — ang pila ng
  pagproseso na ginagawang materyal na nakabatay sa source at maaaring suriin
  ang recording ng isang pulong.
- [`zspan_cli`](../02_Core_Project/zspan_cli/) — ang lokal na client para
  gamitin ang Z-SPAN mula sa sariling computer at workspace ng isang tao.
- [`prompts`](../02_Core_Project/prompts/) — ang mga inilathalang kontrata sa
  synthesis na ginagamit ng daloy ng pagproseso.

Nananatiling hiwalay na repository ang National Civics Catalog upang
mapahusay ng mga tao ang direktoryo ng source nang hindi binabago ang Z-SPAN
application, at upang magamit ng ibang proyekto ang parehong mga endpoint para
sa lubos na ibang layunin.

## Mga pinaninindigan ng proyektong ito

Mga hangganang sinusunod ng proyekto ang mga ito, hindi mga mithiin lamang:

- **Walang editoryal na paghatol sa mga pampublikong opisyal.** Inilalantad ang
  kanilang mga salita nang buo, may malinaw na pagkilala at source. Nasa iyo
  ang paghatol.
- **Walang pagsasama-sama ng datos tungkol sa mga pribadong mamamayan.** Mga
  opisyal na gumaganap sa kanilang pampublikong tungkulin ang paksa ng gawaing
  ito; hindi ginagawan ng profile ang mga residenteng nagsasalita sa
  pampublikong mikropono.
- **Hindi kailanman hinaharangan ang pagbabasa.** Walang paywall, subscription,
  login wall, o registration na kailangan upang basahin ang inilathalang
  nilalaman ng pampublikong rekord.
- **Walang pag-optimize para sa engagement.** Walang walang-hanggang feed,
  recommendation algorithm, o mekanismong nagpapasiklab ng galit. Sadyang
  payapa ang rekord.
- **Isang tao ang sumusuri bago mailathala ang anuman.** Maaaring awtomatiko ang
  pagproseso; hindi ang paglalathala.
- **Hindi pangkomersiyo ayon sa disenyo.** Ginagawang bahagi ng estruktura ng
  lisensiya ang hangganang ito.

## 🌌 Dalhin pa nang mas malayo ang ideya

Nakaayos ang National Civics Catalog ayon sa bawat estado upang lumawak ang
direktoryo ng source sa buong Estados Unidos nang hindi hinihinging gamitin ng
sinuman ang interface o mga pasya sa pagproseso ng Z-SPAN. Gamitin ang mga
endpoint upang bumuo ng kalendaryo ng komunidad, tool sa pananaliksik, proyekto
sa accessibility, sanggunian sa silid-aralan, o bagay na wala pang naiisip dito.

Hindi mahalaga ang ideya dahil pag-aari ito ng isang application. Mahalaga ito
dahil patuloy na makakahanap ang mga tao ng mga bagong paraan upang gawing mas
madaling maabot ang pampublikong rekord.
